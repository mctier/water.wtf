    How to inject See what it does
    What it is

    Not a mod. A client that lives inside the game you already opened.

    No second launcher, no fabric.mod.json entry, nothing in mods/. A loader thread runs Attach, the agent rewrites bytecode at runtime, and the whole client appears in the process already in front of you.

    Getting in

    Launch the game, then attach the jar.

    The injector needs JDK 21. Build the client, start Minecraft 1.21.11, and attach — the client appears in the running process.

    1

    Build it

    Compile against JDK 21; the jar lands in build/libs/. For repeated runs use a fresh -Parchives_base_name — an injected jar is locked by the game.

    2

    Launch Minecraft 1.21.11

    Start the game on Java 21 and get to a world or server. The client attaches to whatever process is already running.

    3

    Attach

    Run inject.bat beside the jar — it finds or installs JDK 21, waits for the game and attaches for you. Double-click the .bat, never the .jar.

    4

    Press right shift

    The Verso opens. Toggle modules, drag panels, bind keys. Default open bind is Right Shift.

    terminal
    # build (JDK 21) — output → build/libs/
./gradlew build -Parchives_base_name=utilitymod-dev

# attach to the running 1.21.11 client
"C:\Program Files\Java\jdk-21.0.12\bin\java.exe" -jar utilitymod-dev.jar

    A Java error popup from double-clicking the jar is a file-association problem on that PC, not the jar itself. Always launch through inject.bat. Windows only.

    Before you ask

    Questions.

    Why inject instead of a normal mod?

    No mod loader entry and nothing in your mods folder. A loader thread runs com.utilitymod.inject.Attach and the agent rewrites bytecode at runtime, so the client appears in the game that's already open.

    Do I need Mixin or a special launcher?

    No. Injection is pure ASM through JVM Attach — Patcher, Patches and Hooks with HEAD, RETURN, REDIRECT and FIELD_STORE kinds. Any vanilla or Fabric launcher works.

    Which version does it run on?

    Minecraft 1.21.11 on Java 21, mapped with Yarn 1.21.11+b3. Windows only for the bundled inject.bat.

    Why does double-clicking the jar throw a Java error?

    That's a file-association problem on that PC, not the jar. Launch through inject.bat, which finds or installs JDK 21 and attaches for you.
